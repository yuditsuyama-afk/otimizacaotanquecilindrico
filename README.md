# Otimização do Custo de um Tanque Cilíndrico

## Descrição
Este projeto busca minimizar o custo de construção de um tanque cilíndrico com volume mínimo de 500 m³, utilizando programação em C++ e técnicas numéricas de otimização.

## Objetivo
Determinar as dimensões do tanque — raio e altura — que minimizam o custo de construção, respeitando a restrição de volume.

## Métodos utilizados
- Função de custo de construção.
- Restrição de volume mínimo.
- Aproximação numérica por diferenças finitas.
- Otimização iterativa e análise de convergência.

## Arquivos
- `tanque.cpp`: código-fonte do programa.
- Arquivos CSV: históricos das iterações e resultados dos testes.

## Como executar
Compile o programa com um compilador C++ compatível e execute o arquivo gerado. O programa permite realizar um teste individual ou comparar diferentes parâmetros de otimização.
